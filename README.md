Problem 1.1: Which feed is best for business?

Using the chick weight data, compare minimum, mean, and maximum weight for each feed type. Assume heavier chickens are better for business. Decide which feed you would buy and defend the choice against at least one alternative.

Problem 1.2: Choosing an insurance provider

Three insurance providers have min, mean, and max customer ratings. The highest average is not automatically the safest choice: a very low minimum rating tells you something about the worst case customers actually experienced. Choose a provider and defend it.
